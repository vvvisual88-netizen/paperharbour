# Paper Harbour

Independent digital bookshop — Good books. New worlds.

This is the complete static website, with three Gumroad purchase links. Open `index.html` to preview locally. No installation or build is needed.

## Edit the shop

Edit `catalogue.js` for product details, prices, covers, sample links, checkout URLs and the contact email. Purchase buttons require `releaseApproved: true` and a supported HTTPS Gumroad or Payhip link. Update layout and colours in `styles.css`; page sections are in `index.html`.

## Hosting

Deploy this repository as a static site. No build command is required; publish the repository root. Keep the files together: cover images and free samples sit beside `index.html`.

## Downloads

Only free sample PDFs are included here. Full paid book files are delivered through Gumroad and must never be added to this repository.

## Contact

The contact link is disabled until a real email address is set in `catalogue.js`.
